# The Daily Reader

A personal, installable literary reading app (Progressive Web App).

## Publish with GitHub Pages

1. Keep the app files in the repository root.
2. Open Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.

After deployment, the site URL should be `https://orewa-sensei.github.io/daily-reader/`.

## Android

Once the website is live, it can be packaged with PWABuilder: https://www.pwabuilder.com/.

## Privacy

Reading preferences and progress are stored locally in the browser.
